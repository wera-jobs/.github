# Getting help

- **Using Wera:** see [wera-jobs.com](https://www.wera-jobs.com), or email **jessechumo@gmail.com**.
- **A bug or a feature idea:** open an issue on the repository it belongs to.
- **A security problem:** do not open an issue. See the [security policy](SECURITY.md).

Please leave resumes, passwords and other personal details out of issues. Issues are public.
