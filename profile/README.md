<h1 align="center">Wera</h1>

<p align="center">Find the jobs that fit you, and the ones that sponsor.</p>

Wera (Swahili slang for a job or gig) watches more than 5,000 company career pages, ranks new postings for each person, and scores the best against their resume. It shows who files H-1Bs and what they pay, builds a tailored resume for each job, and fills in applications so that you only review and press submit.

**Try it at [wera-jobs.com](https://www.wera-jobs.com).**

## Repositories

| Repository | What it is |
|---|---|
| [Wera](https://github.com/wera-jobs/Wera) | Backend: job pipeline, matching, REST API (Go, PostgreSQL) |
| [Wera-Frontend](https://github.com/wera-jobs/Wera-Frontend) | Public site and dashboard (React, TypeScript) |
| [wera-extension](https://github.com/wera-jobs/wera-extension) | Chrome extension that saves jobs and fills applications |
| [wera-admin](https://github.com/wera-jobs/wera-admin) | Admin console for running the service |

## How we work

We ship small changes often, on a fixed quality and security baseline. Every change passes lint, types and tests in CI, commits follow [Conventional Commits](https://www.conventionalcommits.org), and releases are cut with release-please.

Found a security issue? Please read our [security policy](https://github.com/wera-jobs/.github/blob/main/SECURITY.md) and report it privately.
